# Django: Hello, World!

Базовий проєкт Django. Головна сторінка показує:
1. `Hello, World!`
2. назву поточного дня тижня (українською);
3. випадкову цитату зі списку.

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```
Відкрити: http://127.0.0.1:8000

Тести: `python manage.py test`
